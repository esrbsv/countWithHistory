# count With History
  A simple counter app that keeps track of every value it has held. Each time the counter changes, the previous value is saved to a history list, so users can see the full sequence of counts.
  The project uses closures to manage state privately — the counter's value and its history are stored inside a function scope and can only be accessed or modified through returned methods. This keeps the data encapsulated and prevents outside code from changing it directly.
  Features:
- Increment and decrement the counter
- View the full history of past values
- Reset the counter and clear history

A small project for practicing closures and state management in JavaScript.
